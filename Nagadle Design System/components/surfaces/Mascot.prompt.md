Renders the Nagadle turtle. The mascot is the brand's only illustration — use it for empty states, results and the header lockup.

```jsx
<Mascot src="../../assets/mascot-nagadle.png" size={160} bob />
```

Notes
- Never recolour, outline, crop or rotate the mascot beyond the built-in bob.
- One mascot per screen, at one size. It carries emotion; the rest of the UI stays flat.
