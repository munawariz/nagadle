The wave (seigaiha) background band from the brand kit — the only allowed decorative surface.

```jsx
<WavePattern tone="lime" height={140} />
<WavePattern tone="moss" style={{padding:'var(--space-8)'}}><h1 style={{color:'var(--cream)'}}>Streak 12</h1></WavePattern>
```

Notes
- Two-tone and flat. Never gradient it, never fade it out, never put body copy directly on it — use a Card or a chip for text.
- One wave band per screen, usually behind the header or the result panel.
